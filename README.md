# Scholarship-Website# 🏛️ Universal Student Hub

> Your all-in-one platform to find courses, discover scholarships, manage assignments and achieve your academic goals.

---

## 📋 Project Overview

Universal Student Hub is a multi-page static web application built with pure HTML, CSS, and JavaScript — no frameworks, no libraries.

---

## 🗂️ File Structure

```
universal-student-hub/
├── index.html          # Home page
├── scholarships.html   # Scholarships page
├── dashboard.html      # Dashboard page
├── style.css           # Shared styles (all pages)
├── main.js             # Shared JS (nav, theme, modal, toast)
├── dashboard.js        # Dashboard JS (tasks, calendar, chart)
└── README.md           # This file
```

---

## ✨ Features

| Feature | Page |
|---|---|
| Live search with dropdown | Home |
| Dark / Light mode toggle | All pages |
| Opportunity filter tabs | Home |
| Scholarship search & filter | Scholarships |
| Save scholarship (❤️) | Scholarships |
| Task manager (add, complete, delete) | Dashboard |
| Course progress bars | Dashboard |
| Weekly activity bar chart | Dashboard |
| Monthly calendar | Dashboard |
| Login / Sign Up modal | All pages |
| Responsive (mobile, tablet, desktop) | All pages |

---

## 🚀 How to Run

1. Download all files into **one folder**
2. Open `index.html` in your browser
3. No installation needed

---

## 🛠️ Built With

- **HTML5** — Page structure
- **CSS3** — Styling, Flexbox, Grid, Animations
- **JavaScript (ES6)** — DOM manipulation, LocalStorage, Events
